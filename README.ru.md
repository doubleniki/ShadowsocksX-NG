> **Улучшенный форк** [ShadowsocksX-NG](https://github.com/shadowsocks/ShadowsocksX-NG) с модернизированным интерфейсом, улучшенным пользовательским опытом и оптимизированной системой сборки.

## Что нового в этом форке

Эта улучшенная версия развивает оригинальный ShadowsocksX-NG, добавляя значительные улучшения, ориентированные на пользовательский опыт и эффективность разработки.

### Улучшения интерфейса

- **Сохранение размеров окна пользовательских правил**: Редактор пользовательских правил теперь запоминает последний настроенный размер и позицию
- **Быстрое добавление доменов**: Улучшенный редактор пользовательских правил с удобными функциями добавления доменов:
  - Текстовое поле для быстрого ввода доменов
  - Кнопка "Добавить" для мгновенного добавления доменов
  - Кнопка "Добавить из буфера обмена" для извлечения доменов из URL в буфере обмена
  - Умное извлечение доменов из полных URL (автоматически удаляет протокол и префикс www)
  - Определение дубликатов для предотвращения повторного добавления одного и того же домена
  - Валидация ввода для обеспечения правильного формата домена

### Оптимизация системы сборки

- **Оптимизированные workflow GitHub Actions** с многоуровневым кэшированием:
  - Кэширование пакетов Homebrew
  - Кэширование нативных зависимостей (shadowsocks-libev, privoxy, плагины)
  - Кэширование зависимостей CocoaPods
  - Время сборки сокращено на 71-86% (с ~35 минут до 5-10 минут)
- **Умная фильтрация коммитов**: Сборки запускаются только для изменений кода (feat, fix, refactor), а не для обновлений документации или стилей
- **Эффективное управление артефактами**: Различные политики хранения для релизов и feature-сборок

### Современная интеграция с macOS

- **Поддержка macOS 11.0+**: Использование нативных SF Symbols, семантических цветов и современных возможностей AppKit
- **Прогрессивное улучшение**: Расширенные функции на новых версиях macOS при сохранении совместимости
- **Централизованное определение версий**: Утилита OSVersion для чистого определения доступности функций по всей кодовой базе

## Требования

### Для запуска

- **macOS 11.0 Big Sur или новее**
- Рекомендуется: macOS 12.0 Monterey или новее для лучшего опыта

### Для сборки

- Xcode 13.0+ (для цели развертывания macOS 11.0)
- CocoaPods 1.10.1+
- Машина разработки с macOS 11.0+

## Основные возможности

Все функции оригинального ShadowsocksX-NG:

- `ss-local` из shadowsocks-libev 3.2.5
- Поддержка плагинов SIP003: `kcptun`, `simple-obfs` и `v2ray-plugin`
- Обновление PAC через загрузку GFW List с GitHub
- Обмен профилями серверов через QR-код или URL
- Импорт URL профилей серверов из буфера обмена
- Редактор пользовательских правил PAC
- Поддержка [AEAD шифров](https://shadowsocks.org/en/spec/AEAD-Ciphers.html)
- HTTP-прокси через [privoxy](http://www.privoxy.org/)
- Ручной режим прокси для настройки отдельных приложений

## Об оригинальном проекте

Это форк [ShadowsocksX-NG](https://github.com/shadowsocks/ShadowsocksX-NG), который сам по себе является следующим поколением [ShadowsocksX](https://github.com/shadowsocks/shadowsocks-iOS).

### Детали оригинальной реализации

Оригинальный ShadowsocksX-NG был создан для решения проблем поддержки в предыдущей версии:

- **Изменение архитектуры**: Вместо встраивания исходного кода `ss-local`, используется исполняемый файл `ss-local` из Homebrew
- **Фоновый сервис**: `ss-local` запускается как Launch Agent через launchd, сохраняясь даже после выхода из приложения
- **Упрощенная кодовая база**: GUI-код переписан на Swift, удален неиспользуемый legacy-код
- **Более простые обновления**: Зависимости управляются через Homebrew, упрощая обновление версий `ss-local`

### Ключевые отличия

- Прокси-сервис работает независимо от GUI-приложения
- Доступен ручной режим для настройки SOCKS5 прокси для отдельных приложений
- Современная реализация на Swift для лучшей поддерживаемости
